# 📌 Project Overview

This repository contains my journey in learning Data Analysis using Python. It includes practical projects, exercises, and implementations covering essential data science libraries such as NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn. Each project is designed to solve real-world problems through data analysis and visualization techniques.

    🎯 Goal: To build a comprehensive portfolio of data analysis projects that demonstrate proficiency in extracting insights from data and presenting findings effectively.

📁 Completed Projects
🦠 01 - COVID-19 Merged Analysis

A comprehensive analysis of COVID-19 pandemic data across US states, examining relationships between case rates, urbanization, GDP, and population density.

Key Features:

    📊 Statistical analysis of case distribution

    🔍 Correlation analysis between demographic and economic factors

    🤖 Machine Learning models (Linear, Polynomial, and Random Forest Regression)

    📈 Interactive visualizations and outlier detection

    🎯 Risk categorization of states

**Libraries Used:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, SciPy

🚀 Getting Started
Prerequisites

# Clone the repository
```
   git clone https://github.com/ramyarahmadi/Data-Analysis-Learning.git
   
   cd Data-Analysis-Learning
```

# Create virtual environment (optional but recommended)
```
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

# Install dependencies

```
pip install -r requirements.txt
```

**Running the Projects**

**Navigate to the project folder:**

```cd 01-covid_merged-analysis```

**Open Jupyter Notebook:**

```
jupyter notebook
Open the <project_name>.ipynb file and run all cells
```
